THE IDEA

Europe builds windows differently. Australia does not need to become Europe.

The useful question is simpler: which European ideas genuinely improve an Australian home?

The Window Brief looks at the complete window — frame, glass, seals, hardware, installation interface and the way the product fits the house around it.
