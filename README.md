# The Window Brief

Independent, Australian-facing guidance on high-performance European windows for Australian homes.

## Project direction

- Primary language: English (Australia)
- Audience: Australian homeowners, renovators, architects and builders
- Positioning: expert guidance first, sales channel second
- Visual direction: architectural, calm, premium; palette inspired by COLORBOND® tones
- Current preview target: GitHub Pages

## Working principle

This repository is the source of truth for the website. Changes pushed to `main` are intended to deploy automatically to the preview site.
